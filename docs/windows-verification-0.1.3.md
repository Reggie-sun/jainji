15 项跳过包括 Windows 当前权限不支持的文件符号链接用例、POSIX `chmod` 故障注入、显式网络素材库测试及硬件相关用例；不计为验收通过。初次全并发运行还出现资源竞争导致的超时，改为 2 worker、120 秒上限后完整测试通过。开发桌面 smoke 发现旧导航断言已过时；默认脚本已改为覆盖当前界面的关键路径，旧版其他 scope 尚未重验。

用户报告的“源贴纸知识库需要恢复”弹窗对应 `owner.lock` 未正常释放。测试脚本原先强制结束 Electron，重启会停在恢复弹窗；改为正常关闭后，同一隔离目录可重启并恢复反馈回执。用户当前安装版进程仍在运行时不能手动删除其锁；本记录不认定此前那次退出为何中断。
