简辑 0.1.6 — Windows 10/11 x64 安装说明

1. 关闭正在运行的简辑，再双击“jianji-setup-0.1.6.exe”安装。本包未签名，可用 SHA256SUMS.txt 核对文件。安装包内置 FFmpeg 8.0.1、ffprobe、Noto CJK 中文字体、Electron/Node.js 运行时与 Codex；无需另行配置 PATH。
2. “本地随机”和“自己设置”在关闭覆盖或使用手动覆盖时无需模型连接。展示文字必须手动填写，最多两行、每行 12 字。Agent 制作才需要用户自己的模型连接。本包不含账号、API Key 或用户视频。
3. 程序每次启动自动检测 NVIDIA NVENC、AMD AMF、Intel QSV，并用本地画面实际试编码；全部不可用时检测 CPU 编码，不要求固定显卡型号。此包 NVIDIA 编码最低驱动要求为 570，591.74 满足版本要求。目标电脑还需通过启动试编码；仅安装驱动不代表编码器已经可用。
4. CPU 和 GPU 导出都根据当前可用核心数、总内存、启动时可用内存和同时试编码结果自动确定并发，最高 6 路；线程预算按路数均分。CPU 不再固定 1 路，但低核心、低内存或多路探测失败时仍会自动降为 1 路。界面显示实际使用的编码器和路数。
5. 文字、贴纸、滤镜合成仍占用 CPU。自动并发是资源准入，不保证所有素材绝对最快。若可用内存很少，可先关闭不需要的程序，再重启简辑重新探测；请先结束当前批次。

详细验证范围和限制见 windows-verification-0.1.6.md；本机验证驱动为 546.30，591.74、Windows AMD/Intel GPU 出片仍需目标机器验收，不能把版本要求核对当作实机通过。验收样片与抽帧图在“验收样片-0.1.6”目录。全量 Windows 验收清单见 windows-acceptance-spec.md。

如启动时提示“源贴纸知识库需要恢复”，先确认没有另一个简辑实例在运行；不要手动删除 owner.lock。异常中断后可按弹窗选择“安全重建”，它会保留旧知识库副本；已有导出和项目不受影响。

“CC Switch”目录保留官方 MSI、Reggie-sun fork 源码及离线依赖，按该目录说明使用。
