简辑 0.1.4 — Windows 10/11 x64 安装说明

1. 关闭正在运行的简辑，再双击“jianji-setup-0.1.4.exe”安装。安装包内置 FFmpeg、ffprobe、中文字体、Electron/Node.js 运行时与 Codex；无需另外安装或配置 PATH。安装完成后打开简辑，确认本地编码引擎就绪。
2. 登录自己的 ChatGPT 账号，或配置模型 API 与 Key。导入视频后手动填写展示文字，再开始制作；最多两行、每行 12 字，Agent 不会代填或改写。安装包不含账号、API Key 或用户视频；使用在线模型需要网络和相应账号额度。本地随机模式在关闭覆盖或使用手动覆盖时无需模型连接。
3. GPU 加速需要电脑上已有对应显卡及驱动。没有可用 GPU 编码器时会自动使用 CPU。若提示本地导出引擎缺失，请重新安装完整 0.1.4 安装包。

此包基于 main fce917d，包含本地随机导出、结果持久化和最新覆盖规则，以及 Windows 测试发现的文字底色渐隐和登录取消修复。Windows 本机自动化、真实 Electron 本地随机出片、反馈重启恢复、包内环境与正常退出释放知识库锁已验证；详见 windows-verification-0.1.4.md。当前包未签名，仍使用默认 Electron 图标。目标电脑上的交互式安装、真实模型、GPU 和成片人工观看仍需按 windows-acceptance-spec.md 验收。

如启动时提示“源贴纸知识库需要恢复”，先确认没有另一个简辑实例在运行；不要手动删除 owner.lock。异常中断后可按弹窗选择“安全重建”，它会保留一份旧知识库副本；已有导出和项目不受影响，新自动制作会重新识别源贴纸。正常关闭后的隔离重启测试不会出现该提示。

U 盘中的 ffmpeg-release-essentials.zip 是维护人员备用原始包；安装简辑时无需解压。SHA-256 见 SHA256SUMS.txt。
CC Switch 官方安装包、Reggie-sun fork 源码及其离线依赖保留在“CC Switch”目录；简辑本身不要求安装 CC Switch。
