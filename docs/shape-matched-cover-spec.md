# Summary

第一版自动覆盖先确认静态旧贴纸及其可信源像素掩膜，再从形状相容的现有贴纸中选择候选，施加有上限的小幅不透明轮廓扩张。只有最终输出像素完全遮住保守旧贴纸掩膜，且独立的内容安全检查通过，才允许输出；其余情况明确 `UNSAFE`。本规格是已确认的**目标设计**，不表示当前白色矩形渲染已经替换或通过成片验收。实施顺序见 [Implementation Plan](shape-matched-cover-plan.md)。

# Evidence And Current Contract

- 本机真实素材实验记录保存在 `/tmp/jianji-cover-visual-20260923/adaptive-experiment/README.md`：叶子候选在约 1.6 倍面积约束下覆盖 64.5%，竖向候选覆盖 96.8%，形状匹配的星形候选在 7px 扩张、1.291 倍面积时覆盖实验掩膜 100%。掩膜由 90 帧像素稳定性提取并人工核查，测试视频仅 1.8 秒；这些结果不能证明产品级掩膜生成、全片安全或跨素材效果。`delogo` 的局部修补仍产生灰痕。该 `/tmp` 记录不属于可移植的仓库验收证据。
- [源知识合同](source-sticker-knowledge-spec.md)已区分原画面事实、渲染决定与样片结论；当前 [SourceFactsSchema](../src/shared/source-sticker-knowledge.ts)保存分段矩形轨迹和抽帧证据，没有源像素 mask。[CoverPlacement](../src/shared/cover-placement.ts)是近似渲染方案，不是客观旧贴纸事实。
- 当前 [cover-sticker.ts](../src/main/cover-sticker.ts)会把自动覆盖转成贴纸图层，[compiler.ts](../src/main/compiler.ts)按 `opaqueBackground` 生成白色不透明矩形。当前自动选款按同轮统一一款，第一条合格素材触发选款；在形状筛选进入生产后，不能只凭第一条素材决定整轮安全候选。
- 仓库现行规则要求新覆盖层使用白色不透明矩形。实施本规格会改变该产品规则，必须在切换生产渲染时同步更新其规范、提示和相关测试；文档存在本身不改变现行行为。

# Scope And Compatibility

| Included in V1 | Excluded from V1 |
| --- | --- |
| 自动覆盖中已证实存在、位置和可见形状在有效时段稳定的旧贴纸 | 移动旧贴纸、形状变化无法保守界定的旧贴纸 |
| 源像素保守二值 mask、形状匹配、有限扩张、最终输出像素 coverage、独立内容安全检查 | `delogo`、抹除或改写源素材、生成新贴纸 |
| 使用本地已有内置/上传贴纸，沿用同轮统一一款和既有导出队列 | 从历史人工框或近似 `CoverPlacement` 自动推导源 mask |

新自动覆盖不得在缺少可信 mask、候选或证据时回退成白底矩形并报成功。现有手动、`assisted` 和历史冻结任务保留原合同；不能把这些模式的人工框/批准冒充本规格的源像素事实。关闭覆盖时的源贴纸占位逻辑不因本规格改变。

# Source Fact Contract

**REQ-01 — Exact identity.** mask 复用必须匹配现有 `SourceIdentitySchema` 的 SHA-256 指纹、字节数、正向解码尺寸、旋转、时长、时间基准及解释版本，并符合源知识修订和证据有效性要求。不得新增第二套可独立漂移的 `sourceHash` 或文件名匹配规则。更改导出分辨率不会改变源事实，但必须重新计算输出像素 coverage 和样片结论。

**REQ-02 — Source-space mask.** 每个静态贴纸 segment 的事实记录必须包含 `[startMs, endMs)`、源图正向解码坐标系中的整数 bbox、bbox 内原始或近原始分辨率的保守二值 `oldStickerMask`、无损编码及版本、mask 摘要、创建/核查方法与版本，以及关联的原帧 PTS/证据 ID。bbox 明确采用半开像素边界；新增像素字段与现有归一化轨迹并存，解码后的 mask 尺寸、像素数量与 bbox 映射必须可验证。首版以 bbox 内源像素 1:1 网格为证明基准；如采用近原始分辨率，必须证明回投到该网格时保守包含全部标记像素。RLE 或无损 PNG 均可作为有界持久编码；64×64 降采样结果只可作匹配特征或缓存，不能作最终覆盖证明。格式、解码或摘要错误为 `UNSAFE`，不得退化为 bbox 判定。

**REQ-03 — Conservative visible region.** mask 应包含原贴纸所有可见贡献，包括细尖、描边、半透明或抗锯齿边缘；不确定边缘向外保守纳入，而不是向内截断。过大的保守 mask 可以使候选失败，不能为提高通过率裁掉未证明属于背景的像素。存储与解码须设尺寸/负载上限，避免损坏记录导致不受限分配。

**REQ-04 — Temporal validity.** “静态”同时要求位置和可见形状稳定，单帧 mask 不自动代表整个 segment。至少使用 segment 内不同时间点的原帧证据核对形状、边缘和出现/消失区间，并在切镜、遮挡、动画或矛盾证据处拆段或判 `UNSAFE`。多时点抽样仍是抽样证据，不得标成逐帧观察；无法保守界定未观察时段时不发布可用于自动覆盖的 mask。现有 `reviewedRanges`、修订、争议和来源证据仍由源知识 owner 管理。

**REQ-05 — Fact/decision separation.** 源知识只保存旧贴纸及证据；`selectedStickerId`、摆放/缩放、轮廓算法及版本、扩张参数、输出设置、coverage 结果和内容安全结论属于本轮渲染/核查，冻结到适当的模板或验收绑定中。新增覆盖不反写为源事实；源事实修订使受影响但未入队的结论失效，已入队重试沿用冻结结果。

# Candidate And Raster Contract

**REQ-06 — Shape first.** 从现有合法覆盖贴纸目录提取候选实际 alpha。按目标输出设置和可行摆放/缩放计算每款的不透明轮廓，先排除形状不相容者，再从小到大尝试有上限的扩张。形状家族标签仅可加速筛选，不能代替像素计算。扩张不得救完全不匹配的贴纸；面积比、宽高增长和最大半径均有版本化硬上限，具体数值在真实留出样本上冻结后才能上线，不能按个案静默放宽。

**REQ-07 — Whole-round selection.** 保留“同轮全部素材统一一款”的现有合同。正式选款前必须对该轮全部待覆盖的目标、时段和输出设置求共同安全候选；不能用第一条素材的形状代表其他素材。无共同候选时该轮 `UNSAFE`。本地覆盖约束不可由产品 Agent、贴纸美观偏好或轮换规则覆盖；Agent 只能在已通过本地安全门槛的候选中选款，选择后仍按实际冻结图层重新核验。不能为轮换而选用不合格候选。

**REQ-08 — Final-pixel coverage.** 对每个有旧贴纸的输出帧，使用与正式 FFmpeg 渲染一致的正向解码、缩放、补边、像素舍入、图层摆放和启停时序，把源 mask 保守投影到最终输出像素，再加版本化的输出空间安全边距。当前导出不裁剪源画面。以最终真正不透明的轮廓/贴纸 mask 检查 `oldMaskFinal ⊆ coverMaskFinal`，不得以非零 alpha、bbox 相交或浮点几何近似代替。相同栅格状态可缓存一次像素计算，但必须证明每个输出帧的时序与状态受该结果覆盖；帧率转换、补边、贴边和编码后的边缘需用真实导出样片核对。任一像素或时段未覆盖即 `UNSAFE`，不接受 96.8% 一类近似通过。

**REQ-09 — Content safety.** coverage 通过不等于成片通过。新增不透明区域对人物、手、商品主体、重要字幕的侵入必须独立检查；有明确冲突或无法判断时换候选，仍无解则 `UNSAFE`。面积比或一个数值阈值不能替代语义/样片证据。继续使用现有真实样片复核和有界修订流程，不能把模型一句 `pass` 当作像素覆盖或人工全片验收。

**REQ-10 — Fail closed.** 源身份不符、mask 缺失/损坏、静态证据不足、未知时段、无共同安全候选、超扩张上限、coverage 失败、内容安全未通过，均以可解释的 `UNSAFE` 停止新自动覆盖。V1 不调用 `delogo`，不将旧框整块修补，不静默切回白底或透明直接叠加。

# Acceptance Criteria

| ID | Required evidence |
| --- | --- |
| AC-01 | 精确源身份与 mask/证据绑定测试；改字节、改解释版本、坏摘要、坏尺寸、过大负载均不能命中。 |
| AC-02 | 多时间点静态样本可建立保守 mask；形状/出现时段变化、切镜不确定和只有单帧证据明确失败或拆段。 |
| AC-03 | 像素 fixture 覆盖细尖、半透明边缘、贴边、奇数尺寸、旋转、缩放补边、720p/源分辨率及帧率变换；`oldMaskFinal - coverMaskFinal` 对所有合格输出状态为空。 |
| AC-04 | 真实叶子与竖向候选被拒；匹配星形候选在实验素材上通过几何门槛，并有实际导出、配对原图和内容安全结论；实验通过不自动推广到其他素材。 |
| AC-05 | 同轮不同形状目标不存在共同安全候选时失败；不得只按首素材选款。手动/`assisted`、旧任务重试和关闭覆盖行为保持原合同。 |
| AC-06 | 人脸/手、字幕、商品主体邻近案例保留独立内容安全结果；几何通过但内容不安全的样本仍为 `UNSAFE`。 |
| AC-07 | 记录真实视频处理耗时与内存、候选数和被拒原因；长片/多素材批量样本验证成本，不能从 1.8 秒样片推出批量可忽略。 |

# Remaining Risk

可信源像素 mask 的生成与跨时段验证是第一版的主要可行性门槛。现有矩形轨迹、近似 `CoverPlacement`、视觉模型的单帧判断以及本次临时实验 mask 均不足以直接填入该合同。若真实素材无法可靠生成并核查，V1 应保持 `UNSAFE`，不得先上线轮廓 renderer 再补安全门槛。
