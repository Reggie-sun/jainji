# Batch Auto Upload Amendment

## Goal And Authority

依据 2026-10-02 用户要求，跨模板批量制作默认上传并自动绑定，无需逐项选择账号。本修订覆盖旧上传合同中仅针对批量入口的默认关闭、手动选择和提交后清空选择要求；单项目入口与全局上传开关保持现有语义。

## Contract

- 每行上传开关默认开启，可明确关闭；全局关闭时不上传。刷新、再次制作与账号配置更新不把默认改成关闭，用户本轮关闭的草稿保留。
- 模板保存名称去除首尾空白后，只匹配账号保存的有效显示名称（`productName ?? product`），必须唯一且可用。重命名槽位不能通过旧 `product` 名称兜底；不使用子串、模糊匹配、排序或默认第一个账号。
- 批量 UI 显示自动绑定商品，无账号选择器。未匹配、歧义或不可用时显示具体原因，开启上传的所选模板不能开始；用户可修正账号配置，或明确关闭该行上传。
- 制作请求仍只发送原 strict `douyinUpload` 产品槽位。主进程从实际读取的项目名称与当前账号摘要重新匹配，在上传 preflight、模型和导出前拒绝不一致的槽位；仍由原 service 冻结 advertiser、plan、digest 与 pageBatchId。
- 上传授权仍只来自用户点击开始的本次制作。页面加载、刷新、启动恢复不上传；UNKNOWN/fence、每组最多 9 条、停在确定前不变。历史任务和冻结模板不迁移，不改账号私有配置。

## Acceptance And Verification

覆盖已重命名商品、重复模板同名、无匹配、不可用、重名、旧槽位兜底拒绝、跨商品伪造请求拒绝、关闭上传、刷新与下一轮默认。运行 typecheck、batch tests、实际 React/Chrome 交互以及隔离批量上传 smoke；不使用真实账号或真实素材。

## Parent Self-Review

名称只用于选择已保存账号槽位，不能代替 advertiser/plan 身份核验；本地主进程重复校验防止 renderer 携带错误槽位。没有唯一关系时阻断并允许显式不上传，不能悄悄跳过上传或猜测目标。
