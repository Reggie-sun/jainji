# Qianchuan Video Library Implementation And Live Blocker

## Status And Authorization

用户选择实现功能并实际清空各保存 Chrome 自己绑定的广告账户，随后明确已暂停新增上传。本轮实现已形成可提交候选；六账户真实清空**未完成**。首个账号删除确认后未获得完整逐批核验，程序保留未知结果屏障，其余五个账号未提交删除。

## Product Change

入口位于作品页的千川账号设置，支持单账号与全部已配置账号清空；确认区列出名称与 advertiserId。主进程复用账号编辑锁、浏览器绑定及制作/导出/上传准入，逐账号打开新素材库标签；保存映射与原上传账本不变。

页面核对固定 origin/route、唯一 aavid、可见账户 ID、无筛选列表、行 ID 和精确删除弹窗。每批确认前 fsync 私有意图，确认后核对精确数量递减与所选 ID 消失，清空终态需独立刷新。确认后异常保留持久屏障，重启不会重放。取消、超时和连接排空沿原服务控制；不关闭原 Chrome 或原上传标签。
