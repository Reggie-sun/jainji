# Manual Cover Compact Fit Implementation Plan

## Goal

修复人工长条框被巨大气泡图案覆盖的问题。用户选择允许少量超框，优先选择贴合长宽比且额外遮挡最少的本地贴纸。

## Evidence

用户指定的 `2026-10-07T161624.424_edited.mp4` 对应 batch `15449881-7146-4a06-8ece-abab460890c5`。720×1280 输出的人工目标为 `(90,1152,555,128)`；冻结 `local-buy-buy-buy` 摆放为 `(7,994,833,444)`，可见范围为 `(7,994,713,286)`。实际源片和成片在 0、10、25 秒的对照确认底部遮挡显著扩大。

## Scope And Ownership

- `src/main/human-region-cover.ts`：沿用原人工覆盖 owner，替换按名称首个可行款直接采用的选材，比较同轮换优先级内可行图案的实际遮挡。
- `src/main/human-region-geometry.ts`：提供目标周围有限扩展范围，复用原像素映射。
- `tests/human-region-cover.test.ts`：补充真实 FFmpeg 的长条框、紧凑选材、无解和版本轮换回归。
- 正式 AOCI 资产按官方完整批次、CAS 及原子写入维护；其余 dirty files 保留。

## Contract

新正常人工制作（`admission: manual-production-v1`）的搜索范围每边最多扩展目标尺寸的 25%，即完整图案宽高各不超过目标的 1.5 倍；画面边缘仍按原等比图案裁切语义处理。普通 assisted 审阅仍沿旧范围，由实际预览及批准决定；旧冻结 binding 和重试不变。范围仅缩小允许的摆放，不裁切到用户框、不拉伸、不加白底、不放松逐像素 alpha=255。对于同一轮换优先级，每次最多比较 8 款候选，以可见非透明像素数相对目标面积的额外占用总和排序，稳定平局沿用候选 ID；此窗口无可行分配时继续后续窗口，不宣称全目录全局最优。不同目标尺寸用面积归一化，避免整批统一款被大框独占权重。冻结候选 PNG 仅在最终分配成功后发布，落选候选不写入生产目录。

未使用款优先于历史已使用款，连续同款最后，既有每素材目标不重复、跨版轮换和有界回溯保持。无紧凑完整解明确失败。历史 schema、PNG binding、已入队任务和重试不重新解释。默认 Hybrid contour 搜索不改变。

## Acceptance Criteria

1. 巨大方形或气泡不能仅因覆盖了长条框而入选；存在更紧凑可行图案时选择额外遮挡更少的款。
2. 新图案始终完整不透明覆盖整个人工框，允许范围外没有新增可见像素；无合适图案时拒绝，不回退大图案。
3. 多目标分配、轮换、取消、512 次匹配及 4096 次组合上限继续有效。
4. 用户原片与已有成片不改写；在独立诊断目录用相同源和框生成实际覆盖对照，不触发模型、上传或生产任务。

## Verification

先添加并运行可可靠复现长条框失配的失败测试，再实现。运行 `npm run typecheck`、人工覆盖及 Hybrid shape 受影响测试和 owned Harness；复核当前字节对应的 receipt。以用户源片和已保存框核对新 PNG 覆盖率、尺寸、可见像素及合成画面；样本证据不宣称全库视觉验收。最终检查 owned diff，按仓库规则提交、推送并核对 upstream SHA。

## Self-Review

用户方向明确；只收紧新正常人工匹配范围并优化既有选材，不建立第二 renderer、queue、批准或生命周期。上述 25% 每侧为本次“少量超框”的有限工程解释；无法匹配时显式失败，不以扩大范围换取通过。Kimi 只读核查指出全目录逐目标实算会迅速耗尽既有 512 次预算，因此采用 8 款有界窗口和原预算，不全量写盘。原 assisted/manual 准入与旧冻结解释保持。共享 canonical 文档当前存在其他会话改动，本任务不写入该文件；该计划记录本次边界和验证。

## Milestones

1. 复现并实现有限范围及紧凑选材。
2. 验证真实源片对照及兼容回归，维护适用 AOCI，完成 owned Harness 和 Git 交付。
