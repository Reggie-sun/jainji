# Qianchuan Egress Group Mode Switch

## Goal

同一主体从 VPS 上传切换到本机上传 · VPS 出口，或反向切换时，通过明确勾选一次保存整组账号，消除逐账号保存互相阻止的问题。

## Scope And Contract

复用 `QianchuanAccountSettings.savePlan/save` 的唯一映射、写锁、原子保存和变更保护。扩展原账号保存输入，绑定用户核对的原出口设置及完整广告主名单。仅允许同一主体、同一 SSH 别名、端口与 IP 下改变上传模式，不扩大到主体或网络地址迁移。

界面列出受影响账号并要求明确勾选；不改其他账号的产品名称、计划或浏览器绑定。主进程重新读取并核对原设置和完整名单，任一漂移拒绝。全部受影响账号的原任务和浏览器保护检查通过后，一次保存整组；任一检查失败保持原映射字节。旧批次、UNKNOWN、永久屏障及历史目标不变。

## Implementation

1. 在共享账号保存 Schema 增加有界、唯一的主体原设置和广告主名单。
2. 主进程在既有写锁内核对整组，投影新模式后交原保存及保护流程。
3. 账号编辑器显示整组切换勾选与受影响名单，仅经明确同意后解除该组模式冲突，其他冲突仍拒绝。

## Verification

先以回归测试复现原失败，再验证双向整组保存、原计划和名称保留、未确认单账号拒绝、旧名单或原设置漂移拒绝、其他主体冲突拒绝、任一账号任务或浏览器保护阻止全组保存。隔离 Chrome 验证主体选择、明确勾选、失败草稿保留及保存后全部卡片更新；运行类型检查及 owned Harness。实际账号迁移、关闭浏览器和上传不由测试触发。
