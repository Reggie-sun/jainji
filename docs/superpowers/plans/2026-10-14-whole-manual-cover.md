# Whole Manual Cover Implementation Plan

## Goal And Evidence

打通用户手动框选后交给 Agent 的多素材、多框、多版本完整覆盖；普通四角贴纸不算覆盖证据。当前保存项目普查发现 17 个项目、418 条素材、274 条已有框；其中新真实贴纸路径为绿眼贴、舒鼻贴、按摩油，旧白底和自动路径不自动迁移。用户随后明确保留“没框默认不覆盖”，相邻授权会话接手该准入及界面语义，本任务不要求逐素材确认不覆盖。原紧凑搜索只取 1、1.25、1.5 等缩放因子；真实现有 `local-custom-006` 在约 1.05–1.2 的尺寸即可覆盖小角落目标，原搜索漏掉。Agent 将所有素材所有框绑定同款，不同长宽比目标在紧凑限制下还会相互阻断。

## Scope And Ownership

复用 `human-region-cover.ts` 的本地分配、`shape-cover-hybrid-shape.ts` 的栅格搜索、既有模板/队列/验证；调整新正常手动制作的选材分组，补充紧凑搜索尺寸。`human-region-artwork-placement.ts` 负责矩形目标的实际不透明像素整像素平移搜索。`agent-controller.ts` 在明确手动意图后借原 `AssetLibrary.prepare` 加载已审核本地图库并传入同一准备后的资产映射；`shared/cover-sticker.ts` 仅为新正常人工图案声明可用 neutral library ID，不改变旧统一池。新增聚焦测试并接入既有 Harness，更新 Assisted Contract 的整体匹配段及独立整链记录。缺框默认不覆盖、相关界面和测试由用户指定的相邻会话先行提交；本窗口仅在其释放后追加匹配合同段。不同会话的 dirty files 保留，不创建 worktree。

## Contract And Self-Review

仅 `manual-production-v1` 按素材与目标身份独立分配，目标相同身份的多时段保持同款，逐版优先未使用款。本地随机继续要求同素材不同框不同 ID；Agent/手动装饰允许不同目标使用同一合格图案，不额外强制不同款。后者不同目标没有选材互斥，后续无解不回溯已成功的其他目标。创作者仍设计普通装饰，必须覆盖的图层继续由本地强制生成。真实四框素材复现固定512上限在完整候选矩阵查完前耗尽，因此新正常制作的每素材跨版本匹配上限为 `max(512,候选数×segment数)`（图库≤256，人工段≤64），每版4096次组合和10分钟仍保留。按原资源字节hash缓存透明外围裁切，但每次搜索仍重新核原图指纹；矩阵结果缓存沿原模板冻结语义。取消与无解停止，不增加无限重试。既有 assisted 的512、同轮统一款和旧冻结 binding 不改。

新 compact-artwork 搜索增加0.05间隔尺寸及允许范围精确边界尺寸，并完整枚举每个尺寸下的可行整数平移，使用不透明孔洞和可见像素积分图核查。原 contour/artwork 模式及自动形状路径不变。所有输入图案等比、仅画布边界裁切，每个目标像素alpha=255；不加底、不增长轮廓、不缩小用户框。新正常人工制作复用原本地已审核neutral图库，Agent启动也加载原池；另像素审阅既有 phone/notebook 两张纵向资源，仅增加为人工区域覆盖可用，不进入普通四角自动白名单。不新增图片、下载或绕过资源hash，新图库ID不进入旧统一覆盖选择。无实际可行贴纸仍拒绝；不能为成功推测未保存目标或冒充自动识别。

跨项目复现进一步确认原限制把画布外不可见图案也当作画面遮挡。本任务以目标每边25%限定画布内可见占用；画布外只允许边界裁切，完整等比图案宽高仍各不超过目标2倍，避免从巨大图案截取小色块。中部目标不能借此扩大原范围。候选窗口内先优先少裁切，再比较额外可见占用；轮换层级、8款窗口和原有搜索/栅格/匹配预算保持有界。该边缘修订替代紧凑计划的完整raw图案1.5倍解释，保留其限制主体遮挡目的；巨大气泡长条反例继续拒绝并回归测试。

该修订替代新正常手动制作的整批统一选材解释：原统一要求与紧凑不同几何冲突，按目标独立选材由当前“整体覆盖打通”授权的任务内合同变更处理。不是改创作者型号或降低 coverage gate。

## Acceptance And Verification

1. 可靠回归复现粗粒度漏解和混合长宽比整批共用款无解，先红后绿；不同框、版本和取消/无解仍遵守硬约束。
2. 对真实保存框按项目逐素材核查全部目标，不以一个成功片段代表整批；记录未知目标及确实无几何解的范围。
3. 原制作 owner、真实 MiniMax route、原 FFmpeg queue 的多素材完整长度 MP4，以及全时段帧/音轨/文件验证；真实模型、Linux 导出和人工整片视觉接受分列。
4. Typecheck、受影响测试、AOCI 官方维护及 owned Harness；最终审阅 owned diff，提交并 push upstream 核对 SHA。共享源码漂移或真实无解不能伪称 PASS。

## Milestones

复现并修复选材搜索；真实跨素材完整制作与全时段核对；稳定验证和 Git 交付。
